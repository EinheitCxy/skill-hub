# Review and Rendering

Check that panel labels, axes, legend, color contrast, markers, and error bars remain legible at the target size. Check that raster exports retain sufficient resolution and vector exports do not clip labels.

Verify that each caption and body reference uses the same condition names, sample counts, metric direction, and uncertainty definition as the figure contract. Mark any illustration as synthetic in the panel or caption.

Keep the data source and regeneration entrypoint with the figure. If a visual is not regenerated from the declared source, report that limitation rather than calling it reproducible.
