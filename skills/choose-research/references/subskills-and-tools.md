# Subskills and Tools

Use the smallest applicable set. Select a capability only when the current step lacks it; do not invoke this table as a fixed sequence:

| Need | Preferred capability |
| --- | --- |
| Claim and causal-logic audit | `scientific-critical-thinking` |
| Broad but disciplined idea generation | `scientific-brainstorming` |
| Missing evidence review | This package’s `literature-review` entrypoint (use its explicit path or namespace) |
| Primary-paper retrieval | `literature-review`, `read-arxiv-paper`, scholarly databases |
| Identification or statistical gate design | `statistical-analysis`, domain-specific statistics skill |
| Durable multi-stage work | `planning-with-files` |
| Proposal drafting after decision | `scientific-writing` |

## Ordering

For formal direction selection, evidence review precedes brainstorming when novelty matters. Use the remaining capabilities only at the step where they add evidence or decision value.

Do not let brainstorming precede the evidence boundary when novelty matters.
