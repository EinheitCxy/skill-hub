# Artifact Classification

- Source, configuration, tests, and docs: group by purpose and dependency.
- Intermediate data, checkpoints, model caches, downloads, and logs: exclude unless project rules or the user require them; explain reproducibility and size implications.
- Publishable figures, tables, reports, and compact results: include with the relevant feature and their generation source or reproduction instructions.

Classification does not authorize deletion. Preserve files with unclear origin or publication status and ask.
