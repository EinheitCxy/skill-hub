# 完整报告与公式交付

仅在用户明确要求完整报告、综述、七章结构或正式文档时使用。使用一个文档标题和以下二级章节写成连贯论述；未请求未来方向时省略该节：

1. 研究背景与重要性。
2. 核心问题与研究目标。
3. 关键理论、方法或模型（最详细）。
4. 主要发现与核心论据。
5. 主要创新与学术贡献。
6. 共同局限与待解问题。
7. 未来方向（仅当用户要求时）。

若交付 HTML，且 Markdown 含 fenced `math` 块，运行：

```bash
uv run python <skill-dir>/scripts/render_math_html.py <report.md> <report.html>
```

分别检查 LaTeX 结构、渲染器支持和实际显示；确认每个公式具有非零尺寸且未裁切，长公式在独立容器内滚动，不撑宽桌面或手机页面。检查 HTML 中每个展示公式均转为可见的 MathML；转换失败或不可见时，修正 TeX 后重试。不要把未验证的源码视作完成的公式交付。
