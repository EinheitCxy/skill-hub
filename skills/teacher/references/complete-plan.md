# 完整学习计划

仅在用户明确要求完整课程、20 小时计划或十个 session 时使用。

先建立五级学习阶梯。每级写明能力边界、可观察里程碑、一个短自测和进入下一级的前置知识；不要把“看完资料”当成里程碑。

遵循用户给出的时长、水平和课程约束；未指定时，才将核心内容组织为十个两小时 session。每个 session 包含一个核心能力、具体例子、主动练习、至多五题的回忆检查、完成标准以及与下一节的连接。说明暂时排除的内容及其补学条件。若用户提供课程、论文、代码或笔记，优先使用这些材料。

每个 session 结束时只更新：已完成能力、开放缺口、本轮关键修正、下一步最小行动和建议复习点。
